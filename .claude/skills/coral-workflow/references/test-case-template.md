# 测试用例模板

```markdown
# 测试用例

## 模块：{模块名称}

### TC-{编号}：{用例标题}

- **前置条件：**
- **测试步骤：**
  1. ...
  2. ...
- **预期结果：**
- **优先级：** P0 / P1 / P2
- **所属功能模块：**
- **测试结果：** 未执行 / 通过 / 未通过
- **Bug编号：** （未通过时关联）
```

## 覆盖维度检查清单

编写测试用例时，确保覆盖以下维度：

| 维度 | 说明 | 是否覆盖 |
|------|------|---------|
| 正向流程 | 核心路径的每一步 | |
| 边界值 | 空值/极值/特殊字符 | |
| 异常流程 | 网络错误/权限不足/数据冲突 | |
| 兼容性 | 浏览器/设备/分辨率 | |
| 交互细节 | 各种操作反馈 | |
| 性能 | 大数据量/弱网 | |
